# Concepts -- intent, unfunded, disposable

One directory per idea: `docs/concepts/<idea>/`, holding a statement of
work and user stories.

This tree is **non-binding**. Nothing downstream may cite a concept as
authority -- an intention on disk is not a decision. A concept leaves this
tree by being funded, at which point a design record is written in
`docs/design/`.

Concepts are never frozen and are freely deleted.
